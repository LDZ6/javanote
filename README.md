# Java Notes Repository

## Overview

This repository contains a structured collection of **professional Java technical notes** created during long-term study and practice. The content focuses on building a solid Java foundation and gradually expanding into mainstream enterprise frameworks and middleware.

The notes are written in a **technical-blog style**, emphasizing clarity, structure, and practical understanding. This repository serves both as a personal knowledge base and a reference for Java learners.

---

## Repository Structure

* **JavaSE**
  Core Java fundamentals, including syntax, object-oriented programming, common APIs, collections, concurrency, and JVM basics.

* **JavaWeb**
  Web development fundamentals such as HTTP, Servlet, JSP, request/response lifecycle, and session management.

* **SpringMVC Notes**
  Spring MVC architecture, request processing flow, core annotations, and common development patterns.

* **Spring Boot Notes**
  Spring Boot core concepts, auto-configuration mechanism, environment management, and integration with common frameworks.

* **MyBatis Plus Notes**
  CRUD operations, condition wrappers, pagination, code generation, and best practices with MyBatis Plus.

* **Advanced Maven Notes**
  Maven project management, dependency resolution, lifecycle phases, and multi-module project design.

* **Nginx**
  Nginx fundamentals, configuration examples, reverse proxy, and load balancing scenarios.
